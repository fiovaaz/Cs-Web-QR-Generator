Web Tabanlı C# QR Kod Oluşturucu
Bu proje, bilgisayara herhangi bir program yüklemeden, tamamen web tarayıcısı üzerinden C# dili kullanılarak geliştirilmiş bir QR kod üretme uygulamasıdır.
 Kullanılan Teknolojiler & Kütüphaneler
Dil: C# (.NET 8)
Kütüphane: QRCoder (NuGet)
Platform: .NET Fiddle / Replit
Kodun Çalışma Mantığı
Kullanıcı tarafından belirlenen metin veya URL adresi, `QRCoder` motoru yardımıyla şifrelenir. Yazılım, internet bağlantısı olmadan pikselleri hesaplar ve konsol ekranına taranabilir **ASCII (Metin tabanlı) bir QR kod** çizer.
